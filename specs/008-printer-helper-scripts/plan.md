# Implementation Plan: Printer Helper Scripts & Auto-Print

**Input**: Feature specification from [`specs/008-printer-helper-scripts/spec.md`](./spec.md)

---

## Summary

Automate the physical label printing workflow by providing pre-packaged OS-specific helper scripts (Bash for Linux/macOS with CUPS and PowerShell for Windows) and a non-blocking printer dispatch engine. When auto-print is enabled, newly generated PDF labels are immediately sent to the designated printer without manual viewer dialogues or setup friction. Includes a settings "Test Print" utility, safe batch regeneration confirmation guards, and a 10-second process execution timeout.

---

## Technical Context

**Language/Version**: TypeScript 5.4+ / Node.js 18+ (Electron desktop runtime)  
**Primary Dependencies**: `obsidian` API, Node.js built-in `child_process` (zero new external npm dependencies)  
**Storage**: Plugin settings storage (`data.json`) via `ObsidianLabelSettings`  
**Testing**: Jest 29+ / `ts-jest` with Node child process mocking and unit/integration test suites  
**Target Platform**: Linux, macOS, and Windows (Obsidian Desktop)  
**Project Type**: Obsidian Community Plugin  
**Performance Goals**: Print helper dispatch initiated in < 500 ms post-generation; strict 10-second timeout on external script execution  
**Constraints**: 100% offline, zero cloud/network telemetry, zero platform-specific native binaries (Constitution Principles I, III, VI)  
**Scale/Scope**: Immediate single-note prints (Command Palette, context menu, custom modal) and guarded batch regeneration
